# Nepsis Chat 0.2.8

## Highlights

- **Support ticket** — Desktop title bar includes a Support control left of minimize / update. Submit account, voice, billing, or other tickets (stored with category `support`).
- **Nous subscription** — Settings tab with plan cards, billing, and invoice templates (no live charges yet).
- **Keybindings** — Settings tab to remap voice/call shortcuts; defaults include mute, deafen, camera, screen share, disconnect, answer, and decline.
