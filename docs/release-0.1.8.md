# Nepsis Chat 0.1.8

## Highlights

- Single desktop session — launching again focuses the open window instead of starting a second copy
- Silent auto-update with download / applying loader modals (no install-scope wizard)
- **Check for updates** in User Settings → Help & Support
- One-click NSIS installer for cleaner first installs and silent in-place updates

## Notes

- Existing 0.1.7 installs receive this version through the in-app updater after the Desktop Release workflow publishes Windows and macOS assets.
- Chromium may still list GPU/renderer helper processes under the one Nepsis Chat Task Manager group; that is expected.
