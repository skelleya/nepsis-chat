# Nepsis Chat 0.2.3

YouTube playback embeds in chat and DMs.

## Highlights

- **YouTube embeds** — Pasting a YouTube / youtu.be / Shorts link shows a playable player (thumbnail → click to play in place).
- Other links still use the Open Graph preview card.

## Notes

- Uses `youtube-nocookie.com` iframes; player loads after the user clicks play.
