# Nepsis Chat 0.1.9

## Highlights

- After refresh or brief disconnect, automatically reopen the voice channel you were in
- If your camera was on, it turns back on after voice rejoin
- Returning to that server while still connected opens the live voice channel
- Includes prior 0.1.8 desktop polish (single instance, silent updates, Update later badge)

## Notes

- Screen share is not auto-restored (browsers require a fresh user gesture for `getDisplayMedia`).
- Existing 0.1.8 installs receive this version through the in-app updater after Desktop Release publishes.
