# Nepsis Chat 0.2.5

## Highlights

- **Larger screen share stage** — Watching a share uses a denser filmstrip and less padding so the shared screen fills more of the voice pane. Dual focus (screen + camera) gives the screen the majority of the space.
- **PiP drag release** — The floating camera panel ends drag on `window` pointerup/cancel, so you can let go anywhere without it staying stuck in a drag.
- **Stable camera order** — Floating PiP tiles no longer reshuffle when someone speaks; speaking only shows the green ring. Live screen shares also appear in the PiP (wider, contain-fit) while you are in text/DM.
