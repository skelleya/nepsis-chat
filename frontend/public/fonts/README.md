# Fonts

## TWK Everett (headers)

TWK Everett is a commercial typeface (Weltkern). Drop licensed web files here:

| File | Weight |
|------|--------|
| `TWKEverett-Regular.woff2` | 400 |
| `TWKEverett-Medium.woff2` | 500 |
| `TWKEverett-Bold.woff2` | 700 |
| `TWKEverett-Black.woff2` | 800 (optional) |

`index.css` already declares `@font-face` for these names. Until files are present, headers fall back to **Space Grotesk**.
